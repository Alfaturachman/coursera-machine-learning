Selamat datang di repositori dokumentasi perjalanan belajar saya dalam **IBM Machine Learning Professional Certificate**. Repositori ini berisi kumpulan proyek, lab, dan materi dari 5 kursus utama yang mencakup spektrum luas teknik Machine Learning modern, mulai dari analisis data eksploratif hingga Deep Learning.

---

## Kurikulum

Sertifikasi ini terdiri dari 5 modul intensif yang dirancang untuk membangun keahlian praktis dalam menggunakan Python dan berbagai library populer seperti Pandas, Scikit-Learn, Keras, dan TensorFlow.

### 1. [Exploratory Data Analysis for Machine Learning](./01%20Exploratory%20Data%20Analysis%20for%20Machine%20Learning/)

Fokus pada pemahaman data sebelum pemodelan.

- **Module 1:** Sejarah AI Modern & Aplikasinya.
- **Module 2:** Pengambilan & Pembersihan Data (Data Cleaning).
- **Module 3:** Exploratory Data Analysis (EDA) & Feature Engineering.
- **Module 4:** Statistik Inferensial & Uji Hipotesis.
- **Module 5:** Proyek Akhir EDA.

### 2. [Supervised Machine Learning: Regression](./02%20Supervised%20Machine%20Learning%20Regression/)

Mempelajari prediksi nilai kontinu menggunakan teknik regresi.

- **Module 1:** Pengenalan Supervised Learning & Regresi Linear.
- **Module 2:** Data Splits & Regresi Polinomial.
- **Module 3:** Cross-Validation.
- **Module 4:** Bias-Variance Trade-off & Teknik Regularisasi (Ridge, LASSO, Elastic Net).
- **Module 5:** Detail Regularisasi & Optimasi.
- **Module 6:** Proyek Akhir Regresi.

### 3. [Supervised Machine Learning: Classification](./03%20Supervised%20Machine%20Learning%20Classification/)

Membangun model untuk memprediksi kategori atau kelas.

- **Module 1:** Logistic Regression.
- **Module 2:** K-Nearest Neighbors (KNN).
- **Module 3:** Support Vector Machines (SVM).
- **Module 4:** Decision Trees & Random Forests.
- **Module 5:** Ensemble Models (Boosting, Bagging).
- **Module 6:** Menangani Imbalanced Classes.
- **Proyek:** [Laporan Klasifikasi](./03%20Supervised%20Machine%20Learning%20Classification/laporan_klasifikasi.ipynb).

### 4. [Unsupervised Machine Learning](./04%20Unsupervised%20Machine%20Learning/)

Menemukan pola tersembunyi dalam data tanpa label.

- **Module 1:** K-Means Clustering.
- **Module 2:** Metrik Jarak & Tantangan Komputasi.
- **Module 3:** Pemilihan Algoritma Clustering.
- **Module 4:** Reduksi Dimensi (PCA).
- **Module 5:** Reduksi Dimensi Berbasis Jarak & Nonlinear.
- **Module 6:** Faktorisasi Matriks.
- **Module 7:** Proyek Akhir Unsupervised Learning.

### 5. [Deep Learning and Reinforcement Learning](./05%20Deep%20Learning%20and%20Reinforcement%20Learning/)

Menjelajahi arsitektur Neural Networks tingkat lanjut.

- **Module 1:** Pengenalan Neural Networks.
- **Module 2:** Backpropagation & Keras.
- **Module 3:** Neural Network Optimizers.
- **Module 4:** Convolutional Neural Networks (CNN).
- **Module 5:** Transfer Learning.
- **Module 6:** RNN & Long-Short Term Memory (LSTM).
- **Module 7:** Autoencoders.
- **Module 8:** Generative Models.
- **Module 9:** Reinforcement Learning.
